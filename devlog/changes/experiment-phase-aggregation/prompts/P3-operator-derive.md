## Change

1. **Literals (D12's writer side).** The alpha4 phase constants gain `alpha4PhaseFinished = "Finished"` and `alpha4PhaseFailed = "Failed"` alongside the existing four.

2. **The derive branch (D6).** The reconcile switch's `default` case today parks `InProgress` with the comment "not Operator-owned beyond provisioning". P3 makes `InProgress` explicit: `case alpha4PhaseInProgress: return r.deriveTerminalPhase(ctx, instance)` — a method that reads `instance.Status.ScenarioManagerVerdict` and applies **D4/D6**:
   - `"Finished"` → `patchPhase(ctx, instance, alpha4PhaseFinished, <clear message naming the verdict>)`, then park (`ctrl.Result{}, nil`);
   - `"Failed"` → `patchPhase(ctx, instance, alpha4PhaseFailed, <clear message>)`, then park;
   - anything else (absent or unknown value) → park without a write (D4: only known verdicts are trusted; absence = not yet reported).
   The `default` case keeps parking everything else — `Error` and any already-terminal phase never re-transition (stickiness inherited from the existing park architecture; no generation-scoped recovery is introduced). The comment on the switch updates to reflect the new case.

3. **The transition Event (D7, ruling Q4: include).** The reconciler struct gains a `Recorder record.EventRecorder` field; `main.go` wires it from the manager (`mgr.GetEventRecorderFor(...)` following the established kubebuilder idiom). On each terminal transition (the two patchPhase successes above) the operator emits a Normal Event on the instance (`kubectl describe` visibility). A nil Recorder must not panic (defensive, mirroring the `DBProbe` nil-default pattern).

4. **Envtest coverage** (the feature's Failed-derivation proof lives here — D10): Finished derive (synthetic `scenarioManagerVerdict: "Finished"` on an `InProgress` experiment → reconcile → `status.phase == "Finished"` + the Event recorded); Failed derive (synthetic `"Failed"` → `phase == "Failed"` + Event); stickiness/no-regression (a parked `Error` experiment stays `Error` across reconciles — regression-proof of the existing behavior); unknown value ignored (`"SomethingElse"` → phase unchanged); absent verdict (no transition); idempotent re-reconcile (a second reconcile of a terminal experiment performs no phase write); and the ownership proof (the operator's status patches carry only `phase`/`message` — it never writes `scenarioManagerVerdict`).
