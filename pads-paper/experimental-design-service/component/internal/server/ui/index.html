CBSE Experimental Design Service

Design the experiment, save it into the Detail DB, start it (the scenario batch to the Scenario Manager), and finish it (the finalization batch — irrevocable).

Flow state

saved: no started: no finalized: no

1 · Design — parameter entries

Add a value for one of the four varyable parameters (EDS-assigned id ≥ 5).

idparametervalue

1 · Design — recipes (one locator row per scenario's parameter set)

Compose one recipe from entries assigned in this process.

parameterset_idarrival_rate_idservice_rate_idrun_duration_idseed_policy_id

1 · Design — scenarios

Each scenario: priority, number_of_reps, confidence_metric, and its recipe.

indexprioritynumber_of_repsconfidence_metricparameterset_idpublished

2 · Save Experiment

Persist the entries and recipes into the Detail DB (one transaction).

3 · Start Experiment

Pre-flight (every referenced parameterset_id resolves), the availability handshake, and the batch publish of the not-yet-published scenarios.

4 · Finish Experiment

Publish the finalization batch (scenarios [], final true). Irrevocable: once finished, no further Start.
